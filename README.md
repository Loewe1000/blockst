# blockst — Website

Storage branch of https://loewe1000.github.io/blockst/: one folder per
package version with that version's manual (`index.html`, `docs.css`,
`blockst.pdf`), an `index.html` that redirects to the newest, `latest/`
doing the same, and `versions.json`. Written by `scripts/manual-site.py`
from the "Build & Deploy Manual" workflow on every push to `main`; do not
edit by hand. `0.3.0/` is the manual as it was published before versioning
began.
